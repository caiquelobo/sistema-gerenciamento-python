# 🐍 Sistema de Gerenciamento de Registros (Python)

Sistema interativo de console desenvolvido em **Python** para gerenciamento de registros e tarefas, aplicando conceitos fundamentais de **Programação Orientada a Objetos (POO)** e boas práticas de desenvolvimento.

---

## 🚀 Funcionalidades

- **➕ Cadastrar Item:** Adiciona novos registros com título e descrição detalhada.
- **📋 Listar Registros:** Exibe todos os itens cadastrados com ID formatado e status atual.
- **🔍 Buscar por ID:** Localização rápida de itens específicos na lista.
- **🔄 Alternar Status:** Permite ativar ou inativar registros individualmente.
- **❌ Remover Item:** Exclusão de registros por ID.
- **🛡️ Tratamento de Erros:** Validação de entradas para evitar falhas de execução no terminal.

---

## 🛠️ Tecnologias e Conceitos Aplicados

- **Linguagem:** Python 3.10+
- **Paradigma:** Programação Orientada a Objetos (POO)
- **Tipagem:** Type Hinting (`List`, `Optional`)
- **Tratamento de Exceções:** `try/except` para prevenção de erros de conversão (`ValueError`)
- **Formatação de Strings:** Sobrescrita do método especial `__str__`
